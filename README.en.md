# Your town, in Brazilian Portuguese 🌿

A **Brazilian Portuguese translation** of **Animal Crossing: New Leaf — Welcome amiibo**. The project aims to preserve the villagers’ humor and personality, with natural dialogue adapted to the available text-box space.

**[Download](https://github.com/jhonsantosx/animal-crossing-new-leaf-welcome-amiibo-ptbr/releases)** · [Installation and updates](docs/GUIDE.en.md) · [Contribute](CONTRIBUTING.en.md)

> **Work-in-progress preview.** Inherited translations still need review, some dialogue variants remain untranslated, and layout fixes are ongoing. Prepared-entry coverage does not mean complete linguistic or in-game validation. See [status](docs/STATUS.md).

## Supported edition

| Requirement | Details |
| :--- | :--- |
| Game | New Leaf **Welcome amiibo**, North American edition |
| Title ID | `0004000000198E00` |
| Replaced language | English |
| Console | Nintendo 3DS with Luma3DS and **Enable game patching** |

The original New Leaf release (`0004000000086300`) is a different edition. Other editions and official-update combinations have not been confirmed. The patch translates the game into **Portuguese**, not English; English documentation is provided for accessibility.

## Download and play

1. Open **Releases** and download the attached `ACNL_Welcome_amiibo_PTBR_…_Luma.zip`.
2. Extract it and copy **luma** to the SD card root.
3. Enable **Enable game patching** in Luma and start the game.

The automatic **Source code** archives contain documentation, not the installable translation. The [full guide](docs/GUIDE.en.md) covers Citra, folder layout and updates.

**Updating the patch does not require reinstalling the game or deleting your save.** Replace the patch files while the game is closed.

No CIA, full ROM, keys, firmware or saves are included. You need your own installed game.

# Help improve the translation 🌱

[Português brasileiro](CONTRIBUTING.md)

Reports and suggestions in Portuguese or English are welcome. You do not need programming knowledge or internal filenames.

## Report an issue

Search existing issues, then use [the forms](https://github.com/jhonsantosx/ACNL-Welcome-Amiibo-PTBR/issues/new/choose). Include patch version, platform, character/location/event and the actual problem. Add a screenshot of the whole text box and any following page. Phone photos are fine.

Describe reproduction steps if known, but do not replay an entire scene just to submit a report. Do not upload ROMs, CIA files, keys, account details or personal saves. Crop unrelated private information from screenshots.

## Suggest wording

Provide current text, proposed replacement and a brief reason. Screenshots help judge context and space. Current preferences: Brazilian Portuguese, “você”, informal “tá/pra” when appropriate, neutral player wording unless gender is required, and “Bells”, “Hino da cidade” and “Decretos”. These choices can be discussed.

## Pull requests and credit

Documentation pull requests are welcome. For game text, start with an issue: this public repository currently contains documentation and downloads; the working catalog and build pipeline remain separate. Do not attach edited binaries without agreeing on a base first. Control codes affect variables, choices, timing and layout.

Accepted suggestions should be credited in release notes using your chosen public name or handle. You may request not to be named. Response times are not guaranteed. Be respectful when discussing wording or style.
